FastAPI Production API

A production-oriented backend application built with FastAPI, PostgreSQL, RESTful APIs, and GraphQL, with containerized deployment and automated CI/CD using Docker and AWS EC2.

The project demonstrates how REST and GraphQL can coexist in the same backend while following a modern deployment workflow.

🚀 Tech Stack
Technology	Purpose
FastAPI	Backend web framework
Python	Application development
PostgreSQL	Relational database
SQLModel / SQLAlchemy	Database ORM
RESTful API	Standard HTTP API endpoints
GraphQL	Flexible API querying
Docker	Application containerization
GitHub Actions	CI/CD automation
AWS EC2	Cloud deployment
